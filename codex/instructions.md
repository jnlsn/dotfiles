## Personal working preferences

- Follow the repository's instructions and established conventions.
- Carry authorized work through implementation and relevant verification. Ask for clarification only when missing information materially affects the result and cannot be inferred.
- Keep changes focused. Preserve unrelated user work and existing configuration.
- Use plain, concise language. Lead with the result, then explain consequential decisions or limitations.
- Run checks appropriate to the change. Report what was verified and what remains unverified; never claim a check passed without running it.
- Keep PR titles and descriptions concise. Describe the final problem and resulting behavior, include relevant validation, and honor the repository's PR template.
- When reviewing PR feedback, distinguish findings from proposed changes. Act within the user's authorization; do not post comments or messages without explicit authorization.
